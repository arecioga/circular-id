# Anexo - Registro de prompts

Este archivo conservará los prompts utilizados para idear, diseñar, redactar o revisar los materiales de la práctica. No se eliminarán las versiones anteriores; las mejoras se añadirán como nuevas entradas.

## Registro 001 - Estructuración inicial del proyecto

- **Fecha:** 16 de noviembre de 2026.
- **Herramienta:** Codex / ChatGPT.
- **Finalidad:** interpretar el enunciado, organizar la entrega y establecer el perfil de cliente que guiará la web.
- **Prompt del usuario:**

> Necesito hacer lo que indica el contenido del PDF continuando con la empresa Circular ID. Debemos hacer una simulación de perfil de redes sociales. Pero vamos punto por punto. Debemos crear un repositorio de GitHub para la entrega. Paso por paso y vamos incrementando. Debes actuar como un diseñador gráfico. El blog debe estar integrado en la web y debe tener 2 entradas de contenido sobre ello. Hay que tener bien ubicado el perfil del cliente para poder adaptar la web. El diseño debe ser concreto, el prompt debe estar dentro de anexos. Tiene que quedar claro lo que pide la práctica y estar estructurado.

- **Resultado utilizado:** creación de la estructura del repositorio, matriz de requisitos y perfil de cliente provisional.
- **Revisión humana pendiente:** validar el público prioritario, la dirección visual y la modalidad de publicación de los perfiles sociales.

## Registro 003 - Identidad visual «Sello vivo»

- **Fecha:** 16 de noviembre de 2026.
- **Herramienta:** Codex / ChatGPT.
- **Finalidad:** crear una identidad gráfica concreta, escalable y coherente con la investigación de Circular ID.
- **Prompt de diseño utilizado:**

> Diseña una identidad visual vectorial para Circular ID, una solución B2B de etiquetas NFC + QR para verificar productos de moda. Debe transmitir confianza verificable, tecnología accesible y protección de la compra, sin parecer una empresa de ciberseguridad ni una criptomoneda. Crea un símbolo sencillo que una circularidad, verificación e identidad digital; un eslogan; una paleta accesible; un sistema tipográfico; recursos gráficos; tono por canal y aplicaciones para web, LinkedIn e Instagram. El resultado debe funcionar a tamaños pequeños y evitar promesas absolutas de seguridad.

- **Resultado utilizado:** concepto «Sello vivo», símbolo circular con verificación, eslogan «Cada prenda, una prueba de confianza», paleta azul marino-verde-azul y sistema tipográfico Manrope + Inter.
- **Revisión humana pendiente:** validar la dirección antes de aplicarla de forma definitiva a la web y a las redes sociales.

## Registro 004 - Primera página de inicio

- **Fecha:** 16 de noviembre de 2026.
- **Herramienta:** Codex / ChatGPT.
- **Finalidad:** aplicar la identidad «Sello vivo» a una página de inicio responsive y funcional.
- **Prompt de diseño utilizado:**

> Diseña una página de inicio para Circular ID basada en su investigación comercial y en la identidad «Sello vivo». El público principal son responsables de e-commerce, marketing o innovación de marcas medianas de moda; el usuario secundario es el comprador que verifica la prenda. La página debe explicar el valor en menos de un minuto, mostrar una demostración NFC + QR, incluir los resultados de la encuesta con su limitación muestral, explicar el funcionamiento, diferenciar el valor para marcas y compradores, anticipar dos artículos del blog y terminar con una llamada a una prueba piloto. El diseño debe ser concreto, responsive, accesible y evitar promesas absolutas sobre autenticidad.

- **Resultado utilizado:** página de inicio estática con navegación, demostración interactiva, datos de investigación, secciones de funcionamiento y públicos, avance del blog y llamada a demostración.
- **Revisión humana pendiente:** aprobar la narrativa y el diseño antes de crear páginas interiores y artículos completos.
