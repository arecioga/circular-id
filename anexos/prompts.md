# Anexo - Registro de prompts

Este archivo conservará los prompts utilizados para idear, diseñar, redactar o revisar los materiales de la práctica. No se eliminarán las versiones anteriores; las mejoras se añadirán como nuevas entradas.

## Registro 001 - Estructuración inicial del proyecto

- **Fecha:** 16 de noviembre de 2026.
- **Herramienta:** Codex / ChatGPT.
- **Finalidad:** interpretar el enunciado, organizar la entrega y establecer el perfil de cliente que guiará la web.
- **Prompt del usuario:**

> Necesito hacer lo que indica el contenido del PDF continuando con la empresa Circular ID. Debemos hacer una simulación de perfil de redes sociales. Pero vamos punto por punto. Debemos crear un repositorio de GitHub para la entrega. Paso por paso y vamos incrementando. Debes actuar como un diseñador gráfico. El blog debe estar integrado en la web y debe tener 2 entradas de contenido sobre ello. Hay que tener bien ubicado el perfil del cliente para poder adaptar la web. El diseño debe ser concreto, el prompt debe estar dentro de anexos. Tiene que quedar claro lo que pide la práctica y estar estructurado.

- **Resultado utilizado:** creación de la estructura del repositorio, matriz de requisitos y perfil de cliente provisional.
- **Revisión humana pendiente:** validar el público prioritario, la dirección visual y la modalidad de publicación de los perfiles sociales.
