# Redes sociales

Sistema de contenidos y simulaciones publicables de Circular ID para Instagram y LinkedIn.

## Estructura

- `instagram/`: textos y piezas listas para subir a una cuenta real.
- `linkedin/`: textos y piezas listas para una página real.
- `assets/`: fotografía original y recursos compartidos.
- `mockups/`: perfiles simulados utilizados como evidencia académica.
- `render.html`, `render.js` y `social.css`: fuentes editables de las creatividades.
- `anuncio-campana.md`: planificación del anuncio común a ambas redes.

Los nombres de usuario, enlaces, métricas y datos de cuenta son provisionales hasta crear los perfiles reales. Las credenciales nunca deben guardarse aquí.

## Paso a perfiles reales

1. Comprobar la disponibilidad de `@circularid_es` y `/company/circular-id-es`.
2. Crear las cuentas con un correo gestionado por el equipo.
3. Subir el avatar, la portada y los archivos de las carpetas `publicables/`.
4. Subir los vídeos definitivos de las publicaciones 03, ya exportados en MP4 H.264, junto con sus portadas.
5. Sustituir los usuarios y enlaces provisionales, renovar las capturas y añadir las URL reales a la web.

No se han simulado seguidores, reacciones, testimonios ni resultados del anuncio. La estrategia completa y las fichas técnicas están en `docs/05-estrategia-redes-sociales.md`.
