# Entrega final

Aquí se organizarán las capturas y la memoria final en PDF. El PDF seguirá el orden del enunciado y enlazará la web, el repositorio y los dos perfiles sociales.

- `capturas/portada-web-v1.png`: primera portada aprobada.
- `capturas/servicios-web-v1.png`: cabecera de Servicios con aviso de simulación académica.
- `capturas/blog-web-v1.png`: cabecera del blog integrado con dos entradas.
- `capturas/perfil-instagram-simulado-v1.png`: perfil académico de Instagram con cuatro publicaciones y métricas a cero.

## Memoria

La primera versión completa se encuentra en `../output/pdf/Memoria_Circular_ID_Imagen_y_Contenido_v1.pdf`. Incluye 22 páginas con portada institucional —logotipo de la UPSA, cinco integrantes y datos académicos—, identidad, web, blog, privacidad, perfiles, contenidos, vídeos, anuncio, matriz de requisitos y anexos de prompts.
